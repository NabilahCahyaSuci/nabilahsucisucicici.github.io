Pengertian Enkapsulasi

Enkapsulasi adalah konsep dalam Object Oriented Programming (OOP) yang digunakan untuk membungkus data (variabel) dan metode (fungsi) dalam satu class serta membatasi akses langsung ke data tersebut.

Constructor Dasar

Constructor dasar adalah metode khusus dalam pemrograman berorientasi objek (OOP) yang digunakan untuk menginisialisasi atau memberi nilai awal pada atribut suatu objek saat objek dibuat. Constructor memiliki nama yang sama dengan nama kelas dan akan dipanggil otomatis ketika objek dibuat.

// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Buku { String judul; // Constructor Buku(this.judul); } void main() { var buku1 = Buku("Belajar Dart"); print(buku1.judul); }

Jenis-jenis Constructor

  • 1. Default Constructor
  • 2. Named Constructor
  • 3. Parameterized Constructor
  • 4. Constant Constructor
  • 5. Factory Constructor

🔹 Named Constructor

Named constructor digunakan untuk membuat constructor dengan nama berbeda dalam satu class.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A import 'dart:convert'; class Mobil { String? merk; int? tahun; // Parameterized constructor Mobil(this.merk, this.tahun); // Named constructor Mobil.baru() { merk = 'Alya'; tahun = 2025; } // Named constructor dari JSON Mobil.dariJson(Map json) { merk = json['merk']; tahun = json['tahun']; } @override String toString() { return 'Mobil{merk: $merk, tahun: $tahun}'; } } void main() { print('--- Demonstrasi Class Mobil ---'); var mobilA = Mobil('Honda', 2022); print('Mobil A: $mobilA'); var mobilB = Mobil.baru(); print('Mobil B: $mobilB'); String jsonString = '{"merk": "Toyota", "tahun": 2023}'; Map jsonData = jsonDecode(jsonString); var mobilC = Mobil.dariJson(jsonData); print('Mobil C: $mobilC'); Map anotherJsonData = { 'merk': 'Pajero', 'tahun': 2024 }; var mobilD = Mobil.dariJson(anotherJsonData); print('Mobil D: $mobilD'); }

🔹 Constant Constructor

Constant constructor adalah constructor yang digunakan untuk membuat objek yang nilainya tidak dapat diubah (immutable). Constructor ini menggunakan keyword const dan semua field dalam class harus bertipe final.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Warna { final int r, g, b; const Warna(this.r, this.g, this.b); String toString() { return 'Warna(r: $r, g: $g, b: $b)'; } } void main() { const merah = Warna(255, 0, 0); const kuning = Warna(0, 255, 0); print(merah); print(kuning); }

🔹 Initializer List

Initializer list adalah cara untuk menginisialisasi variabel sebelum constructor dijalankan. Biasanya digunakan untuk mengisi field final atau melakukan proses sebelum constructor utama berjalan.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Titik { final double x, y; Titik(double x, double y) : x = x.abs(), y = y.abs() { print('Titik dibuat di (${this.x}, ${this.y})'); } } void main() { print('Membuat objek Titik pertama:'); var titik1 = Titik(4.0, 6.0); print('Titik 1: x = ${titik1.x}, y = ${titik1.y}'); print('\nMembuat objek Titik kedua:'); var titik2 = Titik(-8.0, 11.0); print('Titik 2: x = ${titik2.x}, y = ${titik2.y}'); print('\nMembuat objek Titik ketiga:'); var titik3 = Titik(-3.5, -5.5); print('Titik 3: x = ${titik3.x}, y = ${titik3.y}'); }

🔹 Praktik 1: Multiple Construktor

Materi ini menjelaskan bahwa dalam Dart satu class bisa memiliki lebih dari satu constructor untuk membuat objek dengan cara yang berbeda.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Mahasiswa { String? nama; int? umur; // Default constructor Mahasiswa(this.nama, this.umur); // Named constructor dari Map Mahasiswa.dariMap(Map data) { nama = data['nama']; umur = data['umur']; } // Named constructor tanpa nama Mahasiswa.tanpaNama() { nama = "Tidak diketahui"; umur = 0; } void tampilkan() { print("Nama: $nama, Umur: $umur"); } } void main() { // Objek menggunakan default constructor var mhs1 = Mahasiswa("Nabila", 17); // Objek menggunakan constructor dari Map var data = {"nama": "Andi", "umur": 20}; var mhs2 = Mahasiswa.dariMap(data); // Objek menggunakan constructor tanpa nama var mhs3 = Mahasiswa.tanpaNama(); mhs1.tampilkan(); mhs2.tampilkan(); mhs3.tampilkan(); }

🔹 Publix & Public

Public adalah variabel atau metode yang dapat diakses dari luar class. Private adalah variabel atau metode yang hanya dapat diakses di dalam class saja. Pada Dart ditandai dengan underscore _.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Person { String _name; int age; Person(this._name, this.age); void tampilkanData() { print("Nama: $_name"); print("Umur: $age"); } } void main() { Person person = Person("Suci", 18); person.tampilkanData(); }

🔹 Getter

Getter adalah metode yang digunakan untuk mengambil nilai dari variabel private.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Person { String _name; int age; Person(this._name, this.age); String get getName1 { return _name; } String getName() { return _name; } } void main() { Person person = Person("Suci", 18); print(person.age); print(person.getName()); print(person.getName1); }

🔹 Setter

Setter adalah metode yang digunakan untuk mengubah nilai variabel private.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Person { String _name; int age; Person(this._name, this.age); set setName1(String name) { _name = name; } void setName(String name) { _name = name; } String getName() { return _name; } } void main() { Person person = Person("Suci", 18); print(person.age); person.setName('Nabilah'); print(person.getName()); person.setName1 = 'Cahya'; print(person.getName()); }

🔹 Getter & Setter Validasi

Getter dan setter juga bisa digunakan untuk memvalidasi data sebelum disimpan.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Produk { String _nama; double _harga; Produk(this._nama, this._harga); String get nama => _nama; double get harga => _harga; set nama(String value) { if (value.length >= 3) { _nama = value; } else { print('Nama minimal 3 karakter'); } } set harga(double value) { if (value > 0) { _harga = value; } else { print('Harga harus lebih dari 0'); } } } void main() { var produk1 = Produk('Laptop', 3500000.0); print(produk1.nama); print(produk1.harga); produk1.nama = 'Mouse'; produk1.harga = 1200000.0; print(produk1.nama); print(produk1.harga); }

🔹 Praktik 2: Enkapsulasi Lengkap

Materi ini meminta kita membuat class User dengan konsep enkapsulasi.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class User { String? _username; String? _password; String? _email; // Getter String? get username => _username; String? get password => _password; String? get email => _email; // Setter Username set username(String username) { if (username.length >= 5) { _username = username; } else { print("Username harus minimal 5 karakter"); } } // Setter Password set password(String password) { if (password.length >= 8) { _password = password; } else { print("Password harus minimal 8 karakter"); } } // Setter Email set email(String email) { if (email.contains("@")) { _email = email; } else { print("Email harus mengandung @"); } } } void main() { User user1 = User(); user1.username = "nabila"; user1.password = "password123"; user1.email = "nabila@gmail.com"; print("Username: ${user1.username}"); print("Password: ${user1.password}"); print("Email: ${user1.email}"); }

🔹 Sistem Login Sederhana

Sistem login sederhana menggunakan username dan password untuk memverifikasi pengguna.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class User { String _username; String _password; User(this._username, this._password); String get username => _username; bool login(String username, String password) { return _username == username && _password == password; } void gantiPassword(String lama, String baru) { if (_password == lama) { if (baru.length >= 8) { _password = baru; print('Password berhasil diubah.'); } else { print('Password baru minimal 8 karakter.'); } } else { print('Password lama salah.'); } } } void main() { final User user1 = User('admin_user', 'securePass566'); if (user1.login('admin_user', 'securePass566')) { print('Login berhasil'); } else { print('Login gagal'); } user1.gantiPassword('securePass566', 'newPassword332'); } }

Kesimpulan

Konstruktor digunakan untuk menginisialisasi objek saat class dibuat, sedangkan enkapsulasi digunakan untuk melindungi data dengan membuat variabel private dan mengaksesnya melalui getter dan setter. Kedua konsep ini membantu membuat program lebih terstruktur, aman, dan mudah dikelola.

🔹 Bonus 3: Class Rekening Bank

Class rekening bank digunakan untuk mengelola saldo, setor uang, dan tarik uang.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class RekeningBank { String _nomorRekening; double _saldo; // Constructor RekeningBank(this._nomorRekening, this._saldo); // Method cek saldo void cekSaldo() { print("Nomor Rekening: $_nomorRekening"); print("Saldo saat ini: Rp $_saldo"); } // Method deposit void deposit(double jumlah) { if (jumlah > 0) { _saldo += jumlah; print("Deposit berhasil: Rp $jumlah"); } else { print("Jumlah deposit harus lebih dari 0"); } } // Method tarik void tarik(double jumlah) { if (jumlah > _saldo) { print("Saldo tidak cukup!"); } else if (jumlah <= 0) { print("Jumlah penarikan tidak valid!"); } else { _saldo -= jumlah; print("Penarikan berhasil: Rp $jumlah"); } } } void main() { // Membuat objek rekening RekeningBank rekening1 = RekeningBank("123456789", 1000000); // Simulasi transaksi rekening1.cekSaldo(); rekening1.deposit(500000); rekening1.cekSaldo(); rekening1.tarik(300000); rekening1.cekSaldo(); }
