Pengertian Enkapsulasi

Enkapsulasi adalah konsep dalam Object Oriented Programming (OOP) yang digunakan untuk membungkus data (variabel) dan metode (fungsi) dalam satu class serta membatasi akses langsung ke data tersebut.

Constructor Dasar

Constructor dasar adalah metode khusus dalam pemrograman berorientasi objek (OOP) yang digunakan untuk menginisialisasi atau memberi nilai awal pada atribut suatu objek saat objek dibuat. Constructor memiliki nama yang sama dengan nama kelas dan akan dipanggil otomatis ketika objek dibuat.

// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Buku { String judul; // Constructor Buku(this.judul); } void main() { var buku1 = Buku("Belajar Dart"); print(buku1.judul); }

Jenis-jenis Constructor

  • 1. Default Constructor
  • 2. Named Constructor
  • 3. Parameterized Constructor
  • 4. Constant Constructor
  • 5. Factory Constructor

🔹 Named Constructor

Named constructor digunakan untuk membuat constructor dengan nama berbeda dalam satu class.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A import 'dart:convert'; class Mobil { String? merk; int? tahun; // Parameterized constructor Mobil(this.merk, this.tahun); // Named constructor Mobil.baru() { merk = 'Alya'; tahun = 2025; } // Named constructor dari JSON Mobil.dariJson(Map json) { merk = json['merk']; tahun = json['tahun']; } @override String toString() { return 'Mobil{merk: $merk, tahun: $tahun}'; } } void main() { print('--- Demonstrasi Class Mobil ---'); var mobilA = Mobil('Honda', 2022); print('Mobil A: $mobilA'); var mobilB = Mobil.baru(); print('Mobil B: $mobilB'); String jsonString = '{"merk": "Toyota", "tahun": 2023}'; Map jsonData = jsonDecode(jsonString); var mobilC = Mobil.dariJson(jsonData); print('Mobil C: $mobilC'); Map anotherJsonData = { 'merk': 'Pajero', 'tahun': 2024 }; var mobilD = Mobil.dariJson(anotherJsonData); print('Mobil D: $mobilD'); }

🔹 Constant Constructor

Constant constructor adalah constructor yang digunakan untuk membuat objek yang nilainya tidak dapat diubah (immutable). Constructor ini menggunakan keyword const dan semua field dalam class harus bertipe final.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Warna { final int r, g, b; const Warna(this.r, this.g, this.b); String toString() { return 'Warna(r: $r, g: $g, b: $b)'; } } void main() { const merah = Warna(255, 0, 0); const kuning = Warna(0, 255, 0); print(merah); print(kuning); }

🔹 Initializer List

Initializer list adalah cara untuk menginisialisasi variabel sebelum constructor dijalankan. Biasanya digunakan untuk mengisi field final atau melakukan proses sebelum constructor utama berjalan.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Titik { final double x, y; Titik(double x, double y) : x = x.abs(), y = y.abs() { print('Titik dibuat di (${this.x}, ${this.y})'); } } void main() { print('Membuat objek Titik pertama:'); var titik1 = Titik(4.0, 6.0); print('Titik 1: x = ${titik1.x}, y = ${titik1.y}'); print('\nMembuat objek Titik kedua:'); var titik2 = Titik(-8.0, 11.0); print('Titik 2: x = ${titik2.x}, y = ${titik2.y}'); print('\nMembuat objek Titik ketiga:'); var titik3 = Titik(-3.5, -5.5); print('Titik 3: x = ${titik3.x}, y = ${titik3.y}'); }

🔹 Praktik 1: Multiple Construktor

Materi ini menjelaskan bahwa dalam Dart satu class bisa memiliki lebih dari satu constructor untuk membuat objek dengan cara yang berbeda.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Mahasiswa { String? nama; int? umur; // Default constructor Mahasiswa(this.nama, this.umur); // Named constructor dari Map Mahasiswa.dariMap(Map data) { nama = data['nama']; umur = data['umur']; } // Named constructor tanpa nama Mahasiswa.tanpaNama() { nama = "Tidak diketahui"; umur = 0; } void tampilkan() { print("Nama: $nama, Umur: $umur"); } } void main() { // Objek menggunakan default constructor var mhs1 = Mahasiswa("Nabila", 17); // Objek menggunakan constructor dari Map var data = {"nama": "Andi", "umur": 20}; var mhs2 = Mahasiswa.dariMap(data); // Objek menggunakan constructor tanpa nama var mhs3 = Mahasiswa.tanpaNama(); mhs1.tampilkan(); mhs2.tampilkan(); mhs3.tampilkan(); }

🔹 Publix & Public

Public adalah variabel atau metode yang dapat diakses dari luar class. Private adalah variabel atau metode yang hanya dapat diakses di dalam class saja. Pada Dart ditandai dengan underscore _.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Product { String nama; Product(this.nama); } void main() { var product1 = Product('Keyboard Gaming'); print('Produk dibuat: ${product1.nama}'); }

🔹 Product Class (Dari Kode Awal Nabilah)

Contoh implementasi class Product sesuai kode awal. Menampilkan pembuatan objek Keyboard Gaming.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Produk { final String id; final String nama; final double harga; final int stok; final String kategori; Produk({ required this.id, required this.nama, required this.harga, this.stok = 0, this.kategori = 'Umum', }); @override String toString() => 'Produk(id: $id, nama: $nama, harga: Rp${harga.toStringAsFixed(2)}, ' 'stok: $stok, kategori: $kategori)'; } void main() { Produk laptop = Produk( id: 'P001', nama: 'Laptop Gaming', harga: 15000000, stok: 15, kategori: 'Elektronik', ); Produk smartphone = Produk( id: 'P002', nama: 'Smartphone Flagship', harga: 12000000, stok: 25, ); Produk kamera = Produk( id: 'P003', nama: 'Kamera Mirrorless', harga: 20000000, ); print('=== Daftar Produk ==='); print(laptop); print(smartphone); print(kamera); }
